# Watch grounded repair: execution repaired; semantic gate still fails

2026-09-18. This is a follow-up to the retained failed real-video challenge in
PR #34, not a replacement for its evidence. It extends Watch with experimental
bounded observers; it does not install Jev or a competing perception engine.

The counts are independent reviewer assessments of whether the frame descriptions
support reference events. The program emits 61 single-frame observations and 60
adjacent candidates, **not autonomous adjudicated semantic events**. All model
descriptions remain unverified. Procedure promotions: zero. A zero promotion count
does not mean the model made no false claims.

## Root causes and repairs

1. The prior sparse flow extracted detail frames but sent only four onward. Dense
   replay now explicitly accounts for every one of 61 frames, including failures.
2. Multi-image output indices were not reliably grounded. The same 10s/20s images
   were recognized individually through both chat and generate: API route alone
   was not the fix. Each new observation receives only one verified image, with
   timestamp/hash attached by code rather than generated by the model.
3. The installed thinking model/adapter had envelope and truncation problems.
   Separate Instruct-model probing, strict complete-envelope parsing, bounded
   output, duplicate-field rejection and raw response retention repair execution
   accounting. They do not certify factual answers.
4. Windows default text decoding produced null or mojibake OCR. Binary stdin and
   explicit UTF8 decoding are now tested with non-ASCII text. Recovery receipts
   link to the old receipts instead of overwriting them.
5. Hashing and later reopening image files allowed a custody race. Vision/OCR and
   pixel comparison now consume the same bytes they hash; regression tests mutate
   the source after the vision/OCR read. Model digest/options and clip/source
   time bases are explicit. Admission still cannot reserve resources atomically.
6. Semantic errors persist: mode/workspace confusion, annotation versus sculpting,
   eraser identity, object-screen scale, and switcher classification. More samples,
   correct JSON, explicit warnings and crops did not establish correct perception.

The escape was testing extraction/schema/custody on synthetic controls without
separately testing real image interpretation and actual adapter responses. The
permanent protection added here is retained real failures plus frozen independent
references and strict separation of structural success from semantic success.
No capability promotion is justified by this PR.

Dense replay changes model, settings and inspection budget together; it is **not
an equal-budget efficiency comparison**, isolated causal ablation, or calibration
experiment. No claim at 10, 1,000 or 500,000 arbitrary videos is established.

## Remaining proof boundaries

The input manifest's original-media offset is trusted local provenance, not an
externally pinned cryptographic proof of exact extraction from the original
video. The strict receipt chain covers the local clip/frame bundle. The
experimental pair observer is retained as a negative candidate and is not a
production route. The CPU larger-model probe is diagnostic, not a full replay.
Its first answer reads Object Mode but still makes an incorrect version-visibility
claim; its second repeats the central mode/cursor error. There is no justification
to spend hours rerunning the whole clip with this unchanged CPU configuration.

Doctor previously reported 33 OK, optional ComfyUI offline, zero failures.
Core graph validation: eight capabilities, one pack, no errors. The symlink skip
remains a Windows environment limitation, not a pass.

Final packaging check `d9d66f7`: the new pixel comparator originally imported
undeclared OpenCV/NumPy through the observer. Replaced it with equivalent Pillow
channel-difference operations using an existing declared dependency. Two extra
threshold/dimension tests bring the targeted scope to **126 passed, 1 skipped**.
The complete default local suite then passed: **317 passed, 1 skipped, 7 live-GPU
tests deselected**, in 19.86 seconds. Live-GPU deselection is not a passing result
for those seven tests. No models or heavy generation jobs were started by them.

The unresolved product work is reliable spatial/temporal perception plus an
independent semantic event adjudicator, followed by unseen GUI-video evaluation.
A stronger model is only a candidate until it passes those retained cases.
Transcript summaries, arbitrary confidence thresholds and human reinterpretation
must not silently substitute for autonomous Watch success.
