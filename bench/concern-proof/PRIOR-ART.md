# Prior-art boundary — verified 2026-08-03

The pilot does not support a novelty claim. A primary-source search found close
and material prior art in every major component:

- [Watch & Learn](https://arxiv.org/abs/2510.04673) converts online human
  computer-use videos into executable UI trajectories and reports gains on
  OSWorld.
- [Learning from Online Videos at Inference Time](https://arxiv.org/abs/2511.04137)
  retrieves tutorial videos, infers UI actions, segments them into structured
  trajectories, and selects relevant demonstrations during agent execution.
- [Video2GUI](https://arxiv.org/abs/2605.14747) converts GUI tutorial videos into
  structured interaction trajectories for agent pretraining.
- [Execution Video Reward Modeling](https://arxiv.org/abs/2603.10178) uses
  keyframe/video evidence to judge computer-use task success with temporal
  attribution.
- [Structured Procedural Knowledge Extraction](https://aclanthology.org/2020.nlpbt-1.4/)
  benchmarks instructional-video-to-structured-procedure extraction.
- [Microsoft Agent Skills](https://github.com/MicrosoftDocs/semantic-kernel-docs/blob/main/agent-framework/agents/skills.md)
  packages portable instructions, scripts, and resources with execution and
  audit guidance.
- [OpenClaw self-improving agent](https://github.com/openclaw/skills/blob/main/skills/pskoett/self-improving-agent/SKILL.md)
  promotes tested interaction learnings into Agent Skills.

Current defensible language is therefore: Beast combines source-time visual
evidence, uncertainty-driven reinspection, compiled procedures, real-target
execution receipts, claim gates, crash recovery, resource admission, and
human-approved reflection in one local system. This pilot measures parts of
that combination. It does **not** establish that the combination is unique,
first, patentable, or superior to these systems.

A stronger novelty statement would require a documented claim chart against
the papers, their released code/supplements, commercial products, patents, and
defensive publications. That work remains separate from performance testing.
