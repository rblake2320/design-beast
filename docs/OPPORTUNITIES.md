# Opportunities ledger — doors that opened while building something else

Standing practice: when a build or research result opens a door nobody planned,
it gets an entry here BEFORE the session moves on — internet-checked, impact-assessed,
kept even when it doesn't serve the current project. Entries are real and provable
or they are marked speculative; no hype, no mockups-as-claims.

Entry format: what opened it · what it is · novelty check (searched, dated) ·
potential impact · status (explore now / hold / feeds move #N).

## 001 — The skill compiler: tutorials → verified executable skills
**Opened by:** beast watch (2026-07-31) + Codex's evidence layer (timeline.json,
perceptual fingerprints, faiss retrieval, procedure gate) landing the same day.

**What it is:** an agent watches an arbitrary tutorial video (UE technique, Blender
workflow, any software) and compiles it into a validated skill: align narration +
frames + before/after states → extract candidate actions → resolve against real
APIs (UE Python/MCP) → practice in a disposable sandbox project → capture viewport
+ structural evidence → publish only after validation passes. The procedure gate
already encodes the discipline: a demonstrated action is NOT a learned skill until
it has preconditions, observed postconditions, an implementation, and a passing
validation.

**Novelty check (2026-07-31):** "observational AI" is an emerging 2026 category
(OpenAGI, LittleBird, OpenClaw) — but it watches the USER'S OWN screen to automate
their own repeated patterns. Compiling THIRD-PARTY demonstrated expertise from
internet video into sandbox-validated, evidence-chained skills appears unoccupied.
Beast uniquely holds the supporting pieces: tamper-evident evidence ledger, judge
loop, UE-in-the-loop sandbox, exact-replay environments.

**Potential impact:** every tutorial on YouTube becomes installable capability.
For Beast specifically: the UE/Blender skill library grows by watching, not by
hand-authoring. As a product: "your agent learns your tools' tutorials" is a
category, not a feature.

**Status:** explore next — it is the natural successor to the watch-learn layer
and composes with WIN-PLAN #3 (MCP) and the game lane. Prove-it milestone: one
real UE tutorial compiled into one skill that passes validation in a throwaway
project, with the evidence chain attached.
