# Internet scout — 2026-07-31 gap analysis

What the wider ecosystem has that this stack doesn't. Sources checked: model comparisons
and release coverage current to July 2026. Re-scout quarterly; promote items to STACK.md
only after install + verify.

## Confirmed already covered (no action)
- **Unreal Engine**: UE 5.8's first-party MCP (shipped June 2026 at Unreal Fest) is
  exactly what BeastLab hosts on :8000/mcp — we're on the current path. Optional
  extension: ClaudeUnreal plugin can mount extra toolsets on Epic's server via the
  Toolset Registry. UE6 (~2027) is framed as the successor to this MCP foundation.
- **Image-to-3D**: TRELLIS.2 (MIT, 4B, O-Voxel) + Hunyuan3D 2.1 remain SOTA open options.
- **Local image gen**: ComfyUI + Flux.1-schnell already benchmarked (bench/results/).

## Gaps worth closing (ranked)

### 1. Local video generation — biggest gap
Nothing local for i2v/t2v; all video gen is Higgsfield cloud credits.
- **LTX-2.3** (Lightricks) — 4K/50fps with synchronized audio in one pass, clips ≤20s,
  de facto ComfyUI standard, 3-4x faster than rivals, 32GB-quantized fits the 5090.
- **Wan 2.2** (Alibaba, Apache 2.0) — best open-weight photoreal; t2v + i2v + editing in
  one model.
- **HunyuanVideo 1.5** (Tencent, Apache 2.0) — most cinematic motion/physics.
Fit: plugs into the existing ComfyUI backend + GPU lease scheduler.

### 2. Local TTS / voice cloning
ai-content-engine depends on ElevenLabs (paid, cloud). 2026 local options beat it:
- **Chatterbox Multilingual v3** (June 2026) — 10s-clip voice clone; 65.3% blind-test
  preference OVER ElevenLabs; 23 languages; built-in watermark.
- **Qwen3-TTS** (Jan 2026, Apache 2.0) — 3s-reference cloning, fully permissive license.
- Kokoro (82M, CPU) for fast fixed-voice narration; F5-TTS is CC-BY-NC — skip for work.

### 3. Music is now ship-safe — constraint outdated
STACK.md says AI music isn't ship-safe (Suno/Sony suit). That's about *hosted* services.
**ACE-Step 1.5** (Jan 2026, Apache 2.0, local) generates full songs in seconds on this
GPU with commercial rights; **YuE** (Apache 2.0) for lyric-aligned vocals. BGM for
videos/games unblocks.

### 4. SAM 3 — concept segmentation for QA + masking
Meta's SAM 3 (Nov 2025): segment/track by text concept ("yellow school bus"), 2x accuracy
of prior systems, already integrated in the Ultralytics package we installed in
yolo-vision. Upgrades: auto-QA ("is the product actually in frame?"), precision masks
for inpaint/rembg beyond birefnet.

### 5. SeedVR2 — video/image upscaling with temporal consistency
Diffusion upscaler, ComfyUI-native, open source. Fills the video half of the quality
loop's "upscale/grade" step (Real-ESRGAN-class tools are image-only and dated).

## Install order recommendation
1. SAM 3 into yolo-vision (pip-level, minutes, immediate QA payoff)
2. LTX-2.3 + Wan 2.2 into ComfyUI (tens of GB, unlocks local video lane)
3. Chatterbox v3 (removes ElevenLabs dependency from ai-content-engine)
4. ACE-Step 1.5 (BGM lane + update the STACK constraint)
5. SeedVR2 (after local video gen exists to upscale)
